# 办公小帮手

面向不熟悉电脑的中老年人，在 WPS／Microsoft Office 内提供大按钮、明确的处理范围和操作预览。技术栈为 React + TypeScript + Vite，功能模块与办公软件适配器分开，方便逐个增加功能。

更新：2026-11-27（Asia/Shanghai）。

## 便携版使用

Windows 10／11 x64 用户可完整解压 [OfficeHelper-0.2.1-win-x64.zip](output/portable/OfficeHelper-0.2.1-win-x64.zip)，双击文件夹内的启动程序，选择已安装的 WPS 或 Microsoft Office，再点击“开始使用”。包内自带运行时，无需安装 Node.js 或执行 npm 命令；使用时保持启动器运行。

便携 WPS 18765 正常文字侧栏的字号、加粗、居中、倍数行距、首行缩进及恢复已实机通过；表格只读合计450.5也已通过。中文与空格路径、无系统Node/npm的启动器检查和开始／打开WPS／停止通过。本地旧ZIP尚未包含最新的空表样本生成修复，使用最新源码需重新构建；产物不纳入Git，也未发布Release。

首次启用 Office 会说明并请求本机连接证书授权，Windows 也可能弹出信任确认。便携版 Office 从首次配置到真实任务窗格的完整流程仍待实测。使用、迁移和移除步骤见 [便携版说明](docs/portable.md)。当前包未签名，Office 使用开发侧载方式；尚未完成商店发布与自动更新。

## 从源码开发

需要 Node.js 22.12+（推荐 Node 24 LTS）。

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:5173 可进入**浏览器演示模式**，使用内存中的示例，不读写用户的 Office/WPS 文件，刷新会重置。这个服务同时提供 WPS 开发加载项页面；真实使用入口在办公软件内部，见下方接入步骤。

```bash
npm run check    # 类型检查、单元测试和生产构建
npm run build
npm run preview
```

Office 的历史实测版本为 Windows x64 16.0.20625.20108；WPS 12.1.0.19770 的文字／表格基础验证也为历史记录。当前 WPS 12.1.0.29690 的 5173 开发接入已验证字号、加粗／取消加粗、完整段落居中、倍数行距和首行缩进及各自恢复。段落诊断覆盖部分选字、独占结束边界、混合原值逐段恢复和冲突拒绝；正常侧栏的预览、取消、确认及恢复也通过。表格四格合计 450.5 的原生诊断和正常侧栏只读查询通过，窄侧栏反馈自动滚动及表格大字号显示已实机回归。259 项单元测试、31 项便携版隔离检查、类型检查和生产构建通过。

本机没有可用的桌面Word／Excel，桌面授权未确认。用户授权的专用三段DOCX已上传Word网页版并能阅读，但编辑初始化失败；专项清单尚未上传，脚本未运行，本地HTTPS信任也未完成。**Word新格式、便携Office完整流程均未通过，用户决定暂缓这两项验收，换设备继续。** 接续分支为 `codex/portable-office-window`；完整进度、环境重建及待办见 [项目进度](docs/progress.md)，检查范围见 [验证记录](docs/verification.md)。

新增文字指令：`加粗`、`取消加粗`、`段落居中`、`行距设为1.5倍`、`首行缩进24磅`、`首行缩进1厘米`。段落操作先列出完整段落和原值／目标值，确认后修改；最多20段。Word 行距首版仅处理能确认原有显式倍数行距的普通段落。WPS 文字已接通以上功能，支持原有单倍、1.5倍、双倍或可恢复的多倍行距，并保留原有字符／磅缩进单位供恢复。固定行距、表格、列表及缺失必要接口的段落会被拒绝。字号支持8–72磅、0.5磅精度；行距支持1–3倍、0.05倍精度；首行缩进支持0–144磅，也接受厘米并在预览中显示换算后的磅值；不接受“缩进2字符”参数。

合计只读取当前范围的数值类型单元格，结果只显示在助手内；文本数字、空白、布尔值和错误文本不计入并报告数量。隐藏／筛选行和不同宿主的错误值仍需专项验证。浮点计算最多显示 15 位有效数字。最多读取 5,000 个单元格或 20,000 字符。活动记录仅在内存中保留，不含正文；日常功能没有模型请求、遥测和密钥存储。

```text
src/
  app/                配置与依赖装配
  core/               宿主契约、注册表、执行器、错误和选区校验

  services/           指令理解接口及本地实现
```

## 开发用插件入口

- Office：前期接入环境曾获授权安装微软官方30天开发证书；当前机器未检测到Word／Excel，不能据此前记录视为已配置。具备Office的开发机需先完成该机的证书安装与信任，再运行 `npm run setup:office` 注册开发加载项，运行 `npm run dev:office` 提供 https://localhost:3443 页面；用 Word／Excel 打开 `output/samples/OfficeHelper-Sample.docx` 或 `.xlsx` 试用。`npm run validate:office` 校验清单，`npm run remove:office` 移除注册，`npx office-addin-dev-certs uninstall` 卸载开发证书。
- WPS：运行 `npm run setup:wps` 注册，再运行 `npm run dev` 提供 http://127.0.0.1:5173 页面，从“小帮手 → 帮我一下”打开。注册与 `npm run remove:wps` 只处理 `OfficeHelperWriter`、`OfficeHelperSheet` 两个节点；原有配置备份在 `.local/wps-registration-backups/`。
- `?host=office` 或 `?host=wps&kind=text` / `?host=wps&kind=sheet` 明确要求真实宿主。连接失败会显示错误，绝不自动切换为演示。

以上命令仅用于源码开发；便携版使用独立端口、注册项和专用证书，可与开发版共存。开发接入细节见 [宿主接入](docs/host-integration.md)。

本项目独立编写，参考仓库仅用于结构研究，未整仓复制、运行其安装脚本或导入其业务代码。第三方 npm 依赖的许可证由对应包提供。本项目尚未决定对外发布许可证。
