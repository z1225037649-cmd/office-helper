# 五项扩展能力：使用范围与验收

更新：2026-11-27。本文件描述 0.2.2 源码与候选交付范围；包文件的构建记录另见便携版说明，不代替各版本 Office／WPS 的实机验收。

## 表格排版

在表格中选中一个连续矩形区域，从“全部功能”选择“自动调整列宽”“自动换行”或“突出表头”。三个动作分别预览、确认、恢复，不一次性改写所有格式。

- 列宽由原生宿主按内容计算，影响所选列的整列，含选区外的同列单元格。预览保留原始单位，不编造计算后的宽度。
- 换行只改所选单元格的换行属性；表头强调只将选区第一行加粗，不自动认定工作表第一行是表头。
- 原始列宽、逐格换行和首行粗体状态须可靠读取；合并单元格、保护状态或不完整接口会阻止写入。
- 写入后回读数据和目标属性。恢复时核对原文件、原范围和后续编辑；部分写入或回读失败提示检查原范围并使用原生撤销。

Excel 的排版安全探测要求 ExcelApi 1.13；不满足时入口按能力禁用。WPS 使用桌面 JSAPI 的实际运行时接口及枚举，不猜测枚举数值。

## 打印前检查

对当前连续选区，预览原打印区域、方向和缩放设置，确认后设置为选区打印、横向、宽度 1 页、高度自动。设置值不等于实际页数，助手不估算或伪造分页结果。

宿主缺少可靠设置接口时显示原生操作指引。最终必须在办公软件的打印预览核对实际页数、是否漏列以及文字是否缩得太小；需要时改变纸张或分为多页。打印提交由用户在原生界面完成。已设置的打印属性可按冲突安全规则恢复。

WPS 表格在能确认原工作簿、工作表、窗口和打印参数时，结果提供“打开原生打印预览（不打印）”按钮。点击时再次复核范围和内容，调用专用 `Worksheet.PrintPreview(false)`；接口调用返回不等于已证明预览窗口出现，实际分页仍须原生核对。缺接口或身份不稳定时保留恢复凭据并提示 Ctrl+P。Office 沿用原生“文件 → 打印”指引。

## 另存副本与 PDF

填写新文件名和可选目标文件夹。副本范围为**整篇文档或整个工作簿（所有工作表）**，保留原后缀；与原稿同名、非法名称和不合要求的后缀会被拒绝。

PDF 表单可选择整篇／整个工作簿、仅当前选区，表格还可选择仅当前工作表。预览逐项列明实际范围；空文字选区会拒绝。宿主缺少对应范围接口时给出该范围的原生步骤，绝不静默退回整份文件。尚不提供页码区间或任意多工作表的组合选择。

宿主接口和文件系统能力决定实际路径：

- 支持可靠的原生文件导出与写入时，写入后核验结果，再显示成功及结果入口。
- 只能交给浏览器下载时，结果明确显示“已交给浏览器下载”，不宣称已落盘；由用户核对下载位置和最终文件名。
- 缺少可靠接口、不能保护原稿或无法确认范围时，提供原生保存／导出步骤，明确“尚未验证已保存”。
- 取消、失败、原生指引和浏览器下载不记作已完成保存。外部文件操作不清除上一项仍可恢复的原稿格式修改，也不提供假撤销。

浏览器未披露绝对路径时只显示文件名，不伪造目标文件夹。结果按钮使用适配器保管的不透明标识，界面不能传入任意路径打开。PDF 分页仍应在结果文件中核对。

Office 中的 Excel PDF 会在读取导出字节或选择保存位置之前转为原生指引，要求用户核对所选的“整个工作簿”“活动工作表”或“选定内容”。Word 的选区 PDF 同样使用对应原生指引；整篇 PDF 及文档副本按实际接口能力尝试导出。WPS 文字副本仅对已经保存、没有未保存改动且可核对原文件字节的原稿执行磁盘复制；否则提供原生操作步骤。

WPS 表格的整个工作簿 PDF 先只读枚举 `Sheets`（包含图表表）。仅当所有表均可见、目录与归属稳定、原生枚举及导出接口可靠、目标文件夹可确认为目录时，才忽略各表打印区域、且不指定页码上下限地导出整个工作簿。存在隐藏表、未知可见状态、目录不完整或超过 1,000 张核对范围时，在选择保存位置之前改为原生指引。助手不会自动显示隐藏表或切换活动工作表；导出后仍须核对 PDF 内容、版式和分页。

WPS 表格的选区及当前表分别使用已核对原范围的 `Range.ExportAsFixedFormat`／`Worksheet.ExportAsFixedFormat`，忽略旧打印区域；不会转调工作簿导出器或切换工作表。两种局部范围均须核对仅选中原工作表；成组选择、单表状态未知或归属不符时给出原生指引，不替用户取消分组。WPS 文字选区仅支持能以原生枚举核对的正文区域，使用 `Selection.ExportAsFixedFormat` 并明确传 `ExportCurrentPage=false`，避免将选区所在整页一并导出。页眉、页脚、文本框和未知文字区域使用原生步骤。保存对话框后重核原范围，输出后再核对内容与范围状态；状态变化或回读失败时明确提示可能留下文件，不报告完成，也不自动重试。

## 重复与漏填

先选择判重列和／或必填列，再选择是否有表头、是否忽略首尾空格和大小写。列号均相对当前选区，默认不按姓名判重。可以联合多列，例如姓名与联系方式。

- 保留值类型，数字 `1` 与文字 `"1"` 不相同；复合键不使用容易碰撞的字符串拼接。
- 任一判重列为空时跳过该行判重；必填空白包括空值、空串和全空白字符，`0` 和 `false` 不算空白。
- 类型读取不可靠时拒绝检查。含原生错误单元格的记录整行排除，并报告排除数量，不将同错误码判断为重复。
- 结果计数覆盖完整所选范围，包括隐藏和筛选行；最多展示前 200 条。首次出现记录不计入重复行数。
- 结果中的“定位”使用原始检查范围，选区移动后仍核对原文件和原数据；数据变化时要求重新检查。不会删除、排序或改写源数据。

## 通知模板

填写标题、时间、地点、正文和联系人五项必填字段。预览显示全部内容；可“返回修改”并保留已填信息，再确认创建独立文档。使用固定模板，不发送模型请求，不编造缺失时间、地点或联系人。

执行失败后仍可返回修改已填内容。若检查重复／漏填的文件或范围在确认前发生变化，返回设置时会清空列选择，要求重新核对，不会把原范围的列索引套到新范围。

原文档保持不变。新文档尚未保存时明确提示核对并另存；宿主不支持创建时提供手动新建步骤与可复制文本。演示模式只在内存里生成独立通知预览。

## 实机验收边界

本轮新增能力应分别在 Word、Excel、WPS 文字和 WPS 表格的**独立测试文件**中验证。浏览器及宿主替身测试通过不能写作真实办公软件验收通过。

主要复验步骤：取消预览无写入；确认前切换文件或选区使预览失效；排版不改值／公式／顺序；原生预览无漏列且可读；副本及 PDF 确认范围、取消和重名路径；打开结果并核对位置；报告定位到原始行；通知创建在新文档中；格式恢复不覆盖后续编辑。
