# Windows 便携版

更新：2026-11-27（Asia/Shanghai）。

v0.2.1 面向 Windows 10／11 x64。把 ZIP 完整解压后双击启动程序，即可配置本机已有的 WPS 或 Microsoft Office。包内包含 C# WinForms 启动器、Node 运行时和构建后的插件页面，使用者无需安装 Node.js、npm 或开发工具。

## 开始使用

1. 完整解压 [OfficeHelper-0.2.1-win-x64.zip](../output/portable/OfficeHelper-0.2.1-win-x64.zip)，保留整个文件夹。不要仅复制启动 EXE，也不要直接在压缩包里运行。
2. 双击启动程序，勾选已安装的办公软件，点击“开始使用”。仅使用 WPS 无需 Office 连接证书。
3. 首次启用 Office 时，阅读并确认本机连接证书授权；若 Windows 弹出信任提示，再确认系统操作。拒绝授权时可以只选择 WPS。
4. 首次配置后，保存自己的文件并重新打开办公软件。从 WPS 的小帮手入口或 Office 加载项打开侧边栏，也可点击启动器的“打开 WPS”“试用 Word”“试用 Excel”。
5. 使用时保持启动器运行。点击“停止助手”或关闭窗口会停止本地连接服务，不关闭正在编辑的办公文件；下次双击启动即可重新连接。

当前包未签名，Office 采用开发侧载；组织策略可能限制加载项。Office.js 需要访问微软 CDN，内置运行时不代表 Office 可以完全离线使用。

当前包优先从注册表 App Paths 查找 WPS；注册表缺失时，会校验正在运行的 WPS 进程路径。因此，自定义安装位置未被识别时可先打开 WPS，再检查启动器。若既无注册项也没有运行中的 WPS，当前仍无法识别；不会递归扫描磁盘。这项修复已包含在 v0.2.1 中。

当前0.2.1包包含字号、加粗／取消加粗、段落居中、倍数行距、首行缩进及单步恢复；表格合计只显示结果，不写回单元格。**本机源码新增的平均值查询尚未打入此ZIP**；需重建并重新校验包后才可分发。Word样本的两个正文段落均明确设置单倍行距和零首行缩进。2026-11-27已重新打包，Excel样本实际核对为A1:B5的5行10格，四个金额合计450.5；同时修正便携Office清单版本为 `1.0.2.1`，通过微软清单校验。已有用户试用文件不会被新版覆盖；使用新样本请从新解压文件夹的 `samples` 目录打开。

## 连接证书与续期

Office 使用本产品专用的自签名叶证书，仅用于 `localhost`／`127.0.0.1` 的本机 HTTPS 服务，信任范围为当前 Windows 用户。它与微软共享开发 CA 分开管理；私钥在本机生成，不打包、不随 ZIP 复制给他人。

证书目标有效期为 30 天。启动器在每次启动和运行期间每 6 小时检查一次，到期前 7 天进入续期流程。首次明确授权后会记住维护许可，但 Windows 在新增信任时仍可能再次弹窗，因此不能保证完全无人值守。长时间未运行后再启动，也会重新检查和处理过期证书。

更新先验证新证书、私钥匹配和信任，再切换当前版本；失败会保留旧版本，并记录待回滚的新证书指纹。可以使用“检查与修复”重试。续期会重新启动本地连接服务，插件可能短暂断开。

## 保存位置、迁移和移除

本机数据保存在 `%LOCALAPPDATA%\OfficeHelperPortable\`：

| 路径                                  | 内容                                           |
| ------------------------------------- | ---------------------------------------------- |
| `settings.json`                       | 所选宿主和证书维护授权                         |
| `certificates\`                       | 专用证书、私钥及精确指纹记录；仅当前用户可访问 |
| `samples\`                            | Word／Excel 试用文件，重复启动不会覆盖已有内容 |
| `backups\`                            | 修改前的 WPS 加载项配置备份                    |
| `office-manifest.xml`、`runtime.json` | 本机 Office 注册清单与运行配置                 |

在同一台电脑上移动整个便携文件夹后，重新启动会使用新的页面路径；试用文件继续保存在上述用户目录。复制到另一台电脑时，需要在那台电脑重新配置和授权证书，不要复制证书目录或私钥。

要清理本机接入，先在启动器点击“移除本机配置”。它会停止服务，移除便携版的 Office 注册、两个 WPS 节点和记录中的专用证书，保留其他插件、开发版配置、试用文件和备份。仅删除解压目录不会自动移除这些本机配置。卸载若部分失败会说明原因，修复后可重试。

## 构建与验证

开发者在源码目录运行：

```powershell
npm ci
npm run test:portable
npm run build:portable
```

ZIP输出到 `output/portable/OfficeHelper-0.2.1-win-x64.zip`，同时生成 `.zip.sha256` 校验文件；产物不随Git同步，尚未发布Release。
