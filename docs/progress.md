3. **补充WPS复杂场景验收。** 开发接入的居中、倍数行距、首行缩进及正常侧栏已通过；复杂文件、保护状态、多窗口和原生撤销交互仍需专项实测。保留现有普通正文范围及可恢复规则限制。
4. **WPS表格后续扩展先做只读平均值查询。** 明确非数字／错误／隐藏行边界，不写回公式，保留合计现有语义和测试；列宽、换行和表头格式随后分别设计恢复契约。
