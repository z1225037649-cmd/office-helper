## 换设备接续

先拉取同一分支并读本文件，再读 [验证记录](verification.md) 和 [宿主接入](host-integration.md)。新目录可执行：

```powershell
git clone --branch codex/portable-office-window https://github.com/z1225037649-cmd/office-helper.git
Set-Location office-helper
npm.cmd ci
npm.cmd run typecheck
npm.cmd test -- --configLoader runner
npm.cmd run build -- --configLoader runner
```

已有克隆先确保本地工作已妥善处理，再 `git fetch origin`、切换上述分支并 `git pull --ff-only`。不要重新建框架或把历史最小场景当作全部验收通过。
